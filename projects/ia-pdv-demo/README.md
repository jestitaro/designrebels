# IA en el PDV — Demo interactiva

Sección demo self-contained que simula el flujo de reconocimiento de productos por IA en góndola: un repositor apunta la cámara del celular, la IA detecta cada producto y el formulario de relevamiento se completa solo con los precios.

Pensada para embeberse en `https://www.quartzsales.com/` (sección `#ai-demo`).

## Ruta

`projects/ia-pdv-demo/`

## Ver online

`https://jestitaro.github.io/designrebels/projects/ia-pdv-demo/`

## Tecnología

Un único `index.html` sin dependencias externas (salvo Google Fonts):

- HTML + CSS
- JavaScript vanilla
- Productos de ejemplo embebidos como imágenes en base64

## Identidad de marca

Aplicado el manual de identidad QuartzSales:

- Tipografía **Nunito** en todo el panel de marca/demo (header, CTAs, panel de contexto, góndola, cámara IA).
- Paleta de marca: fondo `#130D5D`, gradiente `#3C9FF1 → #7025E0` en acentos y botones.
- El panel derecho, que simula la app real de campo, conserva **Poppins** — es UI de producto, no comunicación de marca (regla del manual: Nunito para marca, Poppins solo para UI interna de producto).
