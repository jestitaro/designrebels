# Referencia PSMob

Pantallas y componentes oficiales de PSMob exportados de Figma (SVG con imágenes embebidas, ~79 MB).
Los SVG no se versionan (`.gitignore`): acá quedan las hojas de contacto `_hoja-*.png`.
La paleta de la app en `src/tokens.ts` (`app`) se extrajo de estos archivos.

Los productos genéricos (PNG con transparencia, 1254×1254) están en `public/products/`.
